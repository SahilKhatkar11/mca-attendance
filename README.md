<h1>📋 Class Attendance Web Page</h1>

</div>

<h2>📖 About</h2>

<p>
A simple web-based attendance page built using 
<strong>HTML, CSS, and JavaScript</strong>.
It helps mark class attendance quickly and generate a ready-to-share summary.
</p>

<p>
This is a lightweight, front-end-only project designed for quick classroom attendance tracking.
</p>

<hr>

<h2>🌐 Live Demo</h2>

<p>
👉 
https://sahilkhatkar11.github.io/mca-attendance/
</p>

<hr>

<h2>✅ What It Does</h2>

<ul>
  <li>👨‍🎓 Displays a list of students</li>
  <li>✅ Click on names to mark <strong>Present</strong></li>
  <li>❌ Unselected students are treated as <strong>Absent</strong></li>
  <li>📊 Shows present & absent counts</li>
  <li>📝 Generates a ready attendance message</li>
  <li>📋 Copy message with one click</li>
  <li>🌙 Includes a Dark Mode toggle</li>
</ul>

<h2>▶️ How to Use</h2>

<ol>
  <li>Open the live demo link or <code>index.html</code> in a browser</li>
  <li>Click on student names to mark attendance</li>
  <li>Click <strong>Generate Attendance</strong></li>
  <li>Copy the generated message</li>
</ol>
