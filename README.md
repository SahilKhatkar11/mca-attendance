📋 Class Attendance Web Page

A simple web-based attendance page built using HTML, CSS, and JavaScript.
It helps mark class attendance quickly and generate a ready-to-share summary.

✅ What It Does

Shows a list of students 👨‍🎓

Click on names to mark Present

Unselected students are treated as Absent

Displays present & absent counts 📊

Generates a ready attendance message 📝

Copy message with one click 📋

Includes a Dark Mode toggle 🌙

🌐 Live Demo

👉 View here:
https://sahilkhatkar11.github.io/mca-attendance/

🛠️ Tech Used

HTML

CSS

JavaScript

(No backend, no frameworks)

▶️ How to Use

Open index.html in a browser

Mark students by clicking on their names

Click Generate Attendance

Copy the message if needed
